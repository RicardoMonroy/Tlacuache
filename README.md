# Tlacuache Browser

Gestor de archivos para Linux con columnas Miller, doble panel, vista previa y terminal integrada por panel. Escrito en Rust con GTK4, libadwaita y VTE.

Estado: en diseño. Ver `docs/PRD.md` y `docs/ROADMAP.md`.

## Compilar (Arch Linux)

Ver `docs/SETUP_ARCH.md`.

```bash
cargo run -p tlacuache
```
